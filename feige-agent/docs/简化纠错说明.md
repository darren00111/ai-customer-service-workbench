# 试聊与改正 · 1.12.0-preview

完整解压发行包，双击“开始试聊与改正.cmd”。默认可选择模拟店铺，不需要在营店铺。

1. 左侧问一个问题。
2. 右侧选中答错的消息，写正确答案。库存、售价有误时，切换修改类型并选择对应商品或规格。
3. 点“保存并生效”。看到成功提示后，重新问一次验证。

普通答案会自动检查并启用，无需再操作候选、回归和发布。检查未通过或店铺资料已被其他操作更新时，会提示未生效。库存和价格写入商品资料，补货后可再次更新，避免把“售罄”存成永久答案。保存不会向顾客发消息，也不会改写历史回复。

“查看已学会的资料”可查看商品和问答。“更多设置与排查”保留导入、规则、模型连接、版本回退与旧纠错记录；默认收起。旧版保存的待处理案例不会因升级被自动发布。

本版完成的是日常界面和纠错流程简化。模拟店铺使用离线规则；通过合成数据检查不代表已完成真实模型质量、新手参与者测试或平台接入验收。资料自动提取和更广泛的语义理解仍需后续完善。

原桌面快捷方式可能仍指向旧版；请从本次解压目录打开新入口。需要替换快捷方式时，先正常关闭旧版，再运行本目录的“安装到桌面.cmd”。
