# 无店铺体验与验收 · 1.11.0-preview

本轮交付 A（验收基础）和 B（首次体验）的首个可运行版本。无需在营店铺、真实聊天或订单。后续验收不再以首店真实登录作为研发前置条件。

## 普通用户怎么体验

完整解压发行包，双击“开始无店铺体验.cmd”；或启动主程序，选择“立即体验 · 无需店铺”。

1. 选择台球、服装或家居示例店，点击“整理示例资料并开始”。
2. 点击示例问题并查看模拟回复，也可连续追问。回复可以查看依据。
3. 问“能刻字吗”，填写正确答复，点击“整理并检查答复”。
4. 核对内容、适用商品和检查结果，再点“确认用于模拟回复”。
5. 在当前对话再次询问，或在新对话先说明商品再提问。可以撤销最近一次问答更新。

可选导入 CSV 商品表，表头为“商品名称、价格、库存”，可选“材质、规格、别名”。页面提供可下载示例；别名用顿号分隔。文件上限 1MB、1000件商品。系统生成内部标识，检查格式后替换当前模拟商品，并开始新对话。重复导入相同内容不重复发布版本。无效文件不覆盖已生效资料。

示例资料和自填答复均只影响模拟环境。当前使用离线规则，不读取模型配置、密钥、真实店铺注册表或浏览器登录资料，没有真实平台发送入口。体验数据独立保存到 data/sandbox/experience-v1。关闭后可继续；开始新对话保留知识与审计，清除当前试聊上下文。

商品上下文里的纠错只适用于对应商品，不推广到其他商品或店铺。价格、库存和售后处理仍走对应业务资料，不能用普通问答纠错覆盖。此版本演示结构化资料整理和纠错学习，不代表已经完成自由文档知识提取、语义聚类或平台自动采集。

## 模拟平台怎样验收

app/channels/sandbox.py 提供独立、本地持久化事件队列。模拟平台复用实际 ReceptionService、ChannelInbox、LiveLedger 的数据库、草稿校验和回显确认。网络传输、事件和回显为合成内容，既不创建真实连接器，也不发送顾客消息。

已纳入自动检查的情况：

- 消息持久接收、重复去重、同一标识不同正文拒绝、队列重启恢复。
- 新消息或人工回复作废旧稿，售后交人工，未知媒体和撤回暂停。
- 乱序暂停，模拟超时不重发，点击后崩溃恢复为结果不明。
- 迟到回显跨重启确认，不匹配回显不认定成功。
- 知识变化使旧草稿失效，三平台同名顾客和同编号商品价格隔离。

同一工具覆盖三平台的内部消息合同，不证明外部平台协议或客户端兼容。模拟回显不能进入生产验收或真实成交指标。

## 可复现检查

源码环境使用项目虚拟环境：

```
python tests/run_sandbox_acceptance.py
python tests/selftest_experience_browser.py
python tests/run_channel_regressions.py
```

浏览器测试需要本机 Edge 或 Chrome；可用 --browser 指定测试浏览器。模型与平台登录均不参与。发行版提供 --self-test-offline 自检，包括体验纠错回退与模拟回显；自检在临时目录运行。

自动报告：

- verification/sandbox-onboarding-acceptance.json：独立体验与模拟平台检查，含源码指纹。
- verification/experience-browser.json：真实本地浏览器交互、320/700/1240像素及200%缩放检查。
- verification/channel-runtime-regression.json：现有功能与新增功能总回归。
- verification/account-free-package.json：最终包和ZIP完整性、空店铺及凭证扫描。

## 目标与证据分开记录

| 项目 | 本轮范围 | 后续目标 |
|---|---|---|
| 使用流程 | 实际浏览器走通整理、试聊、纠错和回退 | 10名无培训新用户至少9人独立完成，中位耗时不超过10分钟 |
| 商品规模 | 20、200、1000件合成商品导入与查询 | 扩展跨品类资料及检索容量 |
| 自动学习 | 结构化示例、CSV整理，纠错候选自动复测与确认 | 自由文档和历史知识提取、冲突检测及分级生效 |
| 语义质量 | 未调用真实模型，不声称语义指标 | 1200段开发、封存和对抗会话，独立核对标准答案 |
| 持续运行 | 故障与重启恢复场景 | 10店模拟24小时负载，独立报告耗时和资源 |
| 多人交付 | 独立本机资料、空店铺试用包 | 干净机器安装及新手参与者实测 |
| 平台兼容 | 单列未验证，不阻塞无店铺验收 | 用户接入时按当前环境自动检查能力 |

自动界面检查不能代替新手试用，合成功能检查不能代替真实模型质量。本轮不宣称已经达到提取准确率、无需培训完成率、24小时稳定性或真实平台收发能力。
