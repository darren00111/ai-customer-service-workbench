# 多平台店铺工作台使用说明

适用：1.10.0-preview。平台真实收发尚未整体验收，登录与接待分别操作。

## 添加与登录

1. 在主窗口点击“添加店铺”，选择淘宝／天猫、抖店或拼多多，填写名称及品类。每次添加都创建独立店铺资料，不立即登录或自动接待。
2. 同一平台可以添加多家店。同一商家的店可使用相同商家标识；各店价格、库存和政策分别维护。
3. 选择店铺后点击“打开登录入口”。淘宝打开千牛客户端，抖店准备本店独立 Edge 窗口，拼多多准备本店独立浏览器窗口。登录和验证码由店主自行完成。
4. “已打开，待核对”只代表打开入口，不代表已经登录。淘宝／拼多多通过“查看会话与接待设置”检查身份和消息，再核对绑定；实际收发仍需分别验收。
5. 登录不会启动回复。已有接待任务运行时，重新登录会被阻止，请先停止本店接待，避免切换账号影响当前顾客。

## 多店查看

主窗口按平台筛选，显示各店登录／身份、接待状态和验收状态。筛选只改变显示，不停止其他店任务；顶部回复和在线数量仍为全部店铺统计。

总览和非飞鸽店使用完整窗口宽度。查看运行中的飞鸽时显示原客服页；切换平台后，飞鸽恢复独立窗口，后台任务继续运行。

在“店铺知识库”管理当前店的资料。各店待补知识集中在“后台资料补全”，包括待复测、待发布和观察中的数量。点击“补全本店资料”会定位到对应店铺的卡片，后台统计会定时刷新。

## 常用资料补全

选择问题卡片后，可以直接填写：

- 常见问答：标准问题、已确认答案和来源。
- 商品属性：本店商品、属性名称和内容。补一个属性会保留已有属性；同一候选可继续补其他属性。
- 发货规则：已确认的备货／发货准备时间、发货地。

点击“保存为待复测资料”，只生成候选版本，不改变正式回复。接着运行“复测”：通过后会打开关联版本预览。核对变化并勾选确认后，再发布。

候选期间正式资料发生变化时，需要重新核对，避免覆盖新资料。其他复杂字段仍可由熟悉资料格式的人员使用高级入口处理。

上传、填写、模拟回复和未发送草稿都不能算真实补全。卡片在发布后保持观察，新会话确实回答了对应问题并取得发送回显后，才计为已补全。售后待办与资料补全是两类任务。

## 开启接待与当前边界

指定测试会话的自动收发、店铺身份、商品政策和模型配置通过检查后，再按店开启接待。开启全部不会替未授权店铺绕过检查；重启不默认接待。

本版提供三平台统一入口和知识流程，不表示三平台已经正式可用。千牛逐条消息身份仍待真实客户端联调，实际发送继续关闭。实时订单、物流、完整商品同步、媒体与平台原生转接需进一步接入及验收。本机售后待办需要人工在原平台处理。
# 千牛登录入口（1.10.1-preview）

淘宝／天猫通过**千牛桌面客户端**进入商家工作台。在主窗口选择淘宝店铺，点击“打开千牛工作台”，然后自行登录并进入接待中心。

如果没有自动识别到安装位置，会弹出程序选择框。请选择千牛安装目录中的 `AliWorkbench.exe`；工具会记住该位置。也可以点击“选择千牛安装位置”重新设置。不要选择卸载程序、浏览器或安装包。取消选择不会启动客户端，也不会修改已保存的位置。尚未安装千牛时，需要先安装官方千牛客户端。

打开千牛不需要先登录，也不需要先通过会话兼容性检查。登录状态由千牛管理，工具不会读取密码或清除已有登录。多个淘宝店共用本机千牛程序；选择程序位置不等于创建互相隔离的千牛账号窗口。

“已打开，待核对”只表示启动请求已提交。请登录后在接入窗口检查身份与兼容性；当前逐条消息作者、消息标识及真实收发仍待客户端联调，不能仅凭启动成功认定淘宝自动接待可用。
