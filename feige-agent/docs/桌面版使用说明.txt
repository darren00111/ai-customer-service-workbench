抖店智能客服桌面版

新增知识补全卡片、人工改判、候选复测、发布记录和回退。
人工改判会自动关联原平台会话；修改人工回复只预览并暂停自动接待。未发送草稿和模拟验证不计为已补全。
当前开发构建：1.10.0-preview（2026-11-02 按店全店接待和售后待办恢复，三平台尚未完成真实验收）。
在“接入与试聊”核对本店身份、商品、政策、模型及指定测试顾客的自动收发回执后，可单独开启本店全店接待，再从主窗口启动；开启不代表完成真实验收。
关闭全店接待会取消旧回复；主窗口停止会等待任务退出再断开。重启不会自动接待，也不会开启其他店铺。
售后进入本机人工待办；在原平台处理后点击完成，后续新售前可继续自动接待。程序中断后待办可恢复，旧售后不会重发，新的售后会生成新任务。
主窗口接待也会运行已注册的商家导出文件同步；已核对启用的新资料影响后续回复。聊天提炼仍先审核，成交提升需真实数据验证。
绑定拼多多后打开会话，工具会记录页面实际返回的历史；这不是全店历史同步，也不会补发旧消息。
历史中的连续问答会自动生成待审核版本，手机号等个人信息及凭证字段会脱敏。请在店铺资料核对和评测后启用，之后的回复才会使用这些知识。
历史补齐会取消旧草稿并重新判断；若发现有消息未同步到实时连接，会暂停该会话，需在原平台核对。不能把它当作已完成自动断线恢复。
首次打开拼多多独立窗口时先准备消息监听，再进入登录页面；登录和绑定前不会自动发送。
身份绑定前观察到的消息仅供上下文核对，请绑定后使用测试买家发送新咨询。复用已打开的客服窗口而未观察到消息通道时，仍需刷新客服页面。
新增拼多多独立登录、店铺身份核对、网页消息观察、实时文字草稿与逐条审核发送的试接入流程；尚未通过真实店铺验收。
新增千牛客户端只读兼容检查。淘宝会话收发仍需登录后适配，小红书消息仍未接入。
新增持续接待、商品页面资料候选和异常发送恢复，详见“持续接待开发说明.md”。
新增商品卡片关联、跨轮指代与换款处理。卡片的价格不会代替本店已确认资料；未知商品生成资料补全任务。
拼多多可对明确指定的测试顾客检查自动收发；淘宝逐条消息身份仍需适配，实际发送关闭。未开放三平台全店正式自动接待。
同一商家的店铺填写相同商家标识，可以关联同款商品属性；价格、库存、活动及政策分别维护。
在“多平台资料与会话准备”保存共用属性、关联本店商品，再到“店铺资料”预览并启用生成的版本。
导入会话可查看原文并生成草稿，不会发送；实际售后仍在原平台人工处理。

首次使用：先解压完整文件夹，双击“安装到桌面.cmd”。无需管理员权限，安装后会打开程序。
之后双击桌面“抖店智能客服”即可打开，也可在 Windows 开始菜单搜索此名称。
安装位置：%LOCALAPPDATA%\Programs\FeigeCustomerService。
更新方法：关闭软件后，在新发行包里再次运行“安装到桌面.cmd”。已有 data 和 knowledge 不会被更新包覆盖。
直接从发行包双击 FeigeCustomerService.exe 仍可便携运行，便携版的数据与安装版分别保存。
图标、程序和依赖文件安装到固定目录，下载或解压的发行包可单独保留。

在“店铺接待与持续学习”设置本店目标、语气和推荐重点；商家纠错可生成候选知识并用千问回归。
成交与退款结果可从商家确认的导出文件持续导入，完整数据和样本足够时，按授权选择已允许的选购引导。
接入范围和验证边界请看随包“持续学习与成交优化说明.md”；本版没有承诺实际成交率提升。
请先点击“接入与试聊”，在“千问模型设置”保存自己的接口、模型和密钥并验证连接。
本机已配置的密钥不需要重填；发行包不含任何密钥，客户需自行配置。
模型负责语义理解，商品和政策仍需导入并核对；真实订单、物流和商品中心接口尚未接通。

以下关于人工草稿的旧策略适用于历史引擎；新框架按已启用店铺资料自动回答、补问或转售后人工。

1. 双击 FeigeCustomerService.exe 打开控制台。
2. 1.2.1 单店版使用 Edge 把飞鸽原页面显示在工作台右侧。首次切换到 Edge 时需要登录一次，
   登录状态保存在独立的长期 profile 中，后续升级继续复用。
   如果原页面尚未打开，点击“启动店铺”；载入失败时可点击“重新载入原页面”。
   软件启动时不会自动打开任何店铺；只有点击“启动店铺”或“启动全部店铺”才会打开。
   手动关闭某个店铺的浏览器后，控制台会将它设为停止，不会再次强制打开。
3. 登录状态保存在店铺独立的 Chrome profile 中；工作台关闭前会先解除页面绑定。
4. 店铺列表位于 data\stores.json，商品知识库位于 knowledge\stores。
5. 请保留整个 FeigeCustomerService 文件夹，不要只复制 exe 文件。
6. data 目录包含登录状态和客服运行数据，请勿发送给无关人员。

自动补问与人工草稿：
- 缺少商品信息、身高或体重时，系统会自动补问一次，然后等待客户回复。
- 退换货、质量、投诉、议价、资料不足和无法判断的问题不会自动发送。
- 这些问题会出现在“人工草稿”中。可以编辑建议回复，再点击“确认并发送”。
- 发送前系统会重新核对店铺、客户和最新消息；客户有新消息时会取消旧草稿发送。
- 如果已在飞鸽中人工完成处理，点击“已在飞鸽处理”即可关闭待办并恢复后续自动判断。

当前 1.2 验证包只显示一个已验证店铺。人工操作、后台接待、掉线与长时间运行通过后，
再扩展为 10–15 个店铺。
