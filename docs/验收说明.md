# 单店抖店社区版验收说明

2026 年 11 月 3 日，在 Windows 10 64 位环境中基于当前自用桌面版 1.12.0 裁剪。当前社区版并非此前独立编写的 dou-shop-ai 演示工具。

## 保留与裁剪

飞鸽真实接待相关的 app/agent.py、app/engine/page.py、app/engine/pipeline.py、app/engine/store.py、app/engine/watcher.py、app/assets/fga.js 与原版本保持一致。保留千问理解、产品资料、知识发布、上下文、回复、发送确认、售后人工草稿和纠错学习。

平台列表固定为抖店飞鸽，移除其他平台连接实现。StoreRegistry 对包括停用店在内的全部配置限制为一家，Workbench 创建前加锁校验名额，主窗口和知识工作台均不提供第二店入口。自行拼接多店配置会被拒绝加载。

社区版安装目录、快捷方式、任务栏标识、模型密钥位置和默认 Edge 端口分别独立。默认空店铺，无主版本账号和资料；自动发送与自动启动默认关闭，商家可核对资料和模型后设置原引擎自动回复。

## 文件交付

Windows 包包含独立桌面程序、安装脚本、空店铺目录和中文说明，不需要 Python。源码包保留裁剪后的原项目结构，排除账号、聊天、真实知识、浏览器状态、数据库、备份、测试输出和构建缓存。

发行包由脚本按范围生成并检查 ZIP CRC 和 SHA-256。项目自己的开源许可证待所有者确认，未公开上传或发布。
