# 抖店智能客服社区版

基于现有自用桌面版 1.12.0 裁剪，保留原来的飞鸽登录、消息监听、千问语义理解、知识库、自动回复、人工草稿及纠错学习。社区版只支持抖店，只能接入一家店铺。

这份社区版沿用原版本的真实飞鸽网页接待路线，不是重新编写的演示工具。自用主版本保留在原目录，社区版独立安装、独立保存店铺和模型凭证。

## 安装

完整解压 Windows 社区版压缩包，双击「安装到桌面.cmd」，然后打开桌面的「抖店智能客服社区版」。无需安装 Python，需要本机安装 Microsoft Edge 和 Microsoft Edge WebView2 运行环境。

也可以直接打开解压目录里的 FeigeCustomerService.exe。不要在压缩包内直接运行，也不要把社区版覆盖到自用主版本安装目录。

默认安装目录为 %LOCALAPPDATA%\Programs\FeigeCustomerServiceCommunity；本店登录资料、接待记录及知识分别位于该目录的 data 与 knowledge。模型密钥由当前 Windows 账户加密，独立保存于 %LOCALAPPDATA%\FeigeCustomerServiceCommunity\qwen.json，不会读取主版本模型配置。

## 接入你的抖店

1. 点击「添加抖店」，填写店铺名称和经营品类。只允许创建一家，其他平台和第二家店铺均不能添加。
2. 点击「打开登录入口」，在本店独立 Edge 窗口中完成飞鸽登录并核对身份。当前社区版使用独立调试端口 19422，避免默认连接到自用版浏览器。
3. 进入「店铺知识库」，导入自己的商品、问答和经营规则。先预览、核对，再启用。不要使用示例价格或虚构库存。
4. 在「接入与试聊」的千问模型设置中填写自己的模型、百炼地址和密钥，保存并验证连接，先试问本店商品问题。
5. 先用默认建议模式检查回复。确认资料、模型、当前店铺和测试会话后，停止接待，在主窗口「回复模式」选择自动回复并确认，再点击「启动店铺」。
6. 日常在主界面查看飞鸽原页面、运行记录和人工草稿。售后、退款和缺少依据的问题仍交人工；资料或答案有误时沿用原版纠错、核对与发布流程。

社区版首次安装不携带账号、密钥、店铺资料或买家聊天，自动发送和自动启动默认关闭。可保留原版「模拟体验」作为辅助入口，但正式接入和接待沿用真实飞鸽功能。

## 社区版边界

- 只允许抖店飞鸽；移除淘宝、拼多多、小红书的接入入口和平台连接实现。
- 最多一家真实店铺，停用也占用名额。桌面创建、知识工作台创建、注册表加载、批量配置及并发创建均校验限制。
- 保留原版本的商品资料、上下文理解、回复、人工接管与纠错学习模块，不改成只匹配问答的演示引擎。
- 社区版不读取主版本注册表、商品、聊天、浏览器资料或模型密钥；安装路径、快捷方式、任务栏身份和默认浏览器端口均分开。
- 本版没有远程授权、隐藏收费验证、遥测或远程禁用。

真实使用仍需测试者在自己的电脑完成店铺登录、模型验证、消息读取和发送确认。本次开发没有使用真实买家会话进行收发，也未完成 24 小时稳定性验收；本地测试不替代测试者的实际店铺验证。

## 开发与验证

源码结构保留原版本布局：feige-agent 是桌面客户端，feige-fashion-customer-service/scripts 是原资料与分类模块。安装 feige-agent/requirements.txt 后，在 feige-agent 目录运行 community_main.py。

可执行 community_main.py --self-test-offline --self-test-report 报告路径，检查平台、单店及原引擎功能边界。原版接待、模型、学习和状态测试保留在 feige-agent/tests，新增社区界面测试为 community_browser.py。

构建：使用已安装 PyInstaller 的 Python 运行 scripts/build_windows.py；Windows 包及源代码包由 scripts/package_release.py 生成。

本项目自身的开源许可证仍待所有者确认，未擅自选择开源许可。本仓库提供社区版源码，Windows 安装包见 Releases。
